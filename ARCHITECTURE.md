# Tiny Tracks World: Architecture

Unity **6000.3.27f2**, URP 17.3, Input System, uGUI. One scene (`Assets/_Project/Scenes/Main.unity`), generated by
`Tools/setup.sh`. Runtime code lives in `Assets/_Project/Scripts` (assembly `TinyTracks.Runtime`), editor tooling in
`Scripts/Editor` (`TinyTracks.Editor`), and tests in `Tests/EditMode` and `Tests/PlayMode`.

## Content pipeline

```
TrackShapeLibrary.cs  ──(TrackShapeExporter)──▶ Tools/blender/track_shapes.json ──▶ build_tracks.py ─┐
Tools/blender/models/build_{trains,creatures,env}.py ──────────────────────────────────────────────────┤
                                                                                                        ▼
                                          Assets/_Project/Art/Models/<Group>/<Name>.fbx  (vertex colour "Col" = colour × baked AO)
Tools/blender/render_thumbs.py ──▶ Art/UI/Thumbs/*.png      Tools/blender/icons/build_icons.py ──▶ Art/UI/Icons/*.png
Tools/audio/synth_audio.py ──▶ Audio/{SFX,Music,Ambient}/*.wav
Tools/voice/voice_lines.json ──(generate_voice.sh: Kokoro EN / VachanaTTS TH)──▶ Audio/Voice/{en,th}/<key>.wav
                                                                                                        ▼
ProjectSetup.cs (Tools/setup.sh): player/Android settings, URP asset, detail texture, materials, prefabs (+colliders,
Interactable, blob shadows), ScriptableObject definitions (from the *_manifest.json files), ContentLibrary
(Resources/TinyTracksContent), Sunny Valley layout (WorldLayout.cs), Main scene with every system wired.
```

* **One opaque shader, one material.** Every model uses `TinyTracks/ToyLit`: vertex colour (sRGB) × a tiling detail
  texture (R = wood grain, G = speckle, selected by vertex alpha) with wrapped Lambert, SH ambient, rim and main-light
  shadows. This keeps the SRP batcher fully effective. Other shaders: `Ghost` (placement preview), `Water`,
  `SkyGradient` and `Blob` (contact shadows and open-end markers).
* **Blender conventions** are in `Tools/blender/tt_common.py`: the front faces −Y, up is +Z, units are metres, and
  animated parts are child objects with pivots (`Wheel_*`, `Head`, `Tail`, `Canopy`, `Sails`, `Arm`, `WingL/R`), plus
  empties (`BogieFront/Rear`, `CouplerFront/Rear`, `SmokePoint`).

## Railway engine (pure C#, fully unit-tested)

| Type | Role |
|---|---|
| `TrackShapeLibrary` | Geometry of every piece: connectors (local position + outward heading) and paths (polylines sampled every 0.1 m, cumulative arc length). Straight 4 m, short 2 m, tight curve r=4 m 90°, gentle r=8 m 45°, S-curve r=5 m (6 m forward, 2 m sideways), switches, cross, buffer stop, bridges (0.8 m hump), tunnel, ramp (to 2 m), station, depot, level crossing, elevated straight. |
| `TrackGraph` | Pieces are nodes and matching connectors are edges. A link needs the same position (±0.15 m) and opposite headings (±5°). Supports add, remove, rebuild links, duplicate rejection, overlap detection (with vertical clearance for elevated track), open ends, networks, nearest point and validation. |
| `TrackSnapping` | Forgiving placement: it attaches a chosen connector to an open end (yaw snapped to 45° and positions quantised to 1 mm, so loops close exactly). Without a nearby end it places the piece free on a 0.5 m grid. |
| `TrainSpine` | A train's route: the spans it has traversed plus the head position. Carriages are sampled at fixed distances behind the head, so they follow the exact route the locomotive took, even if a junction is flipped mid-train. It also provides look-ahead (dead ends, stations, crossings) and reversal. |

## Runtime systems (MonoBehaviours under `Systems`)

| System | Notes |
|---|---|
| `GameManager` | Modes (Menu, Build, Train, Decorate, Explore), the shared undo stack (`CommandStack`), tap routing, Play / New World / Clear. |
| `InputManager` | Touch and mouse: tap, drag, long press, pinch, twist and two-finger pan. UI touches never reach the world. Drag handlers (ghosts, moving pieces) get first claim. |
| `CameraController` | Elevated orbit rig with smooth pan, zoom and twist, distance-dependent pitch, follow, reset and bounds. |
| `TrackNetworkManager` | Owns the `TrackGraph`. Pooled piece visuals, pop-in, auto pillars under elevated track, accessories (station building, depot shed, crossing barriers), open-end markers and tappable switch arrows. |
| `TrackPlacementController` | Ghost, snap, rotate, confirm (tap the ghost or the same button again), drag-and-release, long-press to move, delete mode, undo and redo. |
| `DecorationManager` / `DecorationPlacementController` | Placed scenery (saved), with the same flow as tracks. Items can't stand on ground-level track. |
| `TrainManager` / `TrainController` / `TrainVehicle` / `TrainEffects` | Consist of a locomotive plus up to 3 carriages. Speed levels 1.6, 2.8 and 4.2 m/s. Brakes before dead ends using v = √(2·a·d), pauses 3 s at stations, closes crossings and reverses on GO at a dead end. Wheels spin and steam engines puff smoke. Engine and rolling loops follow speed. If track under the train is deleted, the train hops off with a puff. |
| `WorldManager` / `TerrainGenerator` / `AmbientAnimator` | Procedural Sunny Valley terrain and lake, static dressing from `WorldDefinition.props`, clouds, birds, and one update loop for every ambient animation. |
| `Interactable` | Tap reactions: animal sound, nod and tail swish; tree sway; house squash; windmill spin; station chime; person wave. |
| `AudioManager` | Music, ambience, narrator voice and pooled SFX with a per-clip cooldown. Separate music, SFX, ambient and voice volumes; music and ambience duck while the narrator speaks. |
| `SaveManager` | Versioned JSON (`world.json` plus `world.bak.json`, `settings.json`), atomic writes, corruption fallback, debounced autosave and saves on pause or quit. Links are reconstructed from type and pose. |
| `PerformanceManager` | Low, Medium and High presets, auto-detect (32-bit or low RAM selects Low), and an FPS governor. |
| `UIManager` | The whole UI is built in code with picture-only buttons (`ToyButton`) and hold-to-confirm for risky actions. Text appears only in the grown-ups' panel and the narrator caption. Implements `IGuideTargets` (what the guide can point at). |
| `Narrator` (UI) | The conductor: speaks a line (`AudioManager.PlayVoice`, which dips the music), shows the caption in a speech bubble (Mitr font, Latin and Thai), and animates a tap or drag hand towards screen targets evaluated every frame (UI elements or world points such as the ghost or the train). |
| `Guide` (UI) | The first-play tour (13 steps, each with a voice line, target, done-condition and assist) and free-play guidance: a tip on first entering each mode, idle tips, event reactions with cooldowns, and the help button. Anti-stuck rules: a step already done counts at once, wandering off to another mode is led back, hints repeat every 9 s while idle, and after 3 hints the guide performs the step (twice-failed assists skip it). |
| `Localization` (Core) | The active narrator language (`auto` follows the device: Thai or English). Lines come from `Tools/voice/voice_lines.json` via `ContentLibrary.voice`. |

## Data (ScriptableObjects)

`TrackPieceDefinition`, `TrainDefinition`, `DecorationDefinition`, `WorldDefinition`, `AudioConfig`, and
`ContentLibrary` (an index plus shared materials and icons). Future worlds (Snowy Valley and others) are new
`WorldDefinition` assets with their own terrain settings and layout.
